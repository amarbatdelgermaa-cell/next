# Next.js Dashboard — Монгол тайлбартай код

Энэ хавтас нь таны илгээсэн `app(1).7z` архивын `app` кодыг **Монгол тайлбартай** болгосон хувилбар юм. Тайлбарууд `// ТАЙЛБАР:` болон `/* ... */` хэлбэрээр бичигдсэн бөгөөд ажиллах код биш.

## Багшид тайлбарлах гол файлууд

- `app/dashboard/page.tsx` — статистик болон сүүлийн 5 нэхэмжлэх
- `app/dashboard/invoices/page.tsx` — нэхэмжлэх хайлт, хүснэгт, хуудаслалт
- `app/ui/invoices/status.tsx` — төлөвийн ногоон/шар өнгө
- `app/ui/invoices/invoice-form.tsx` — нэмэх/засах форм
- `app/lib/data.ts` — мэдээлэл унших
- `app/lib/actions.ts` — нэмэх/засах/устгах, нэвтрэх үйлдлүүд
- `app/lib/db.ts` — PostgreSQL холболт
- `app/ui/login-form.tsx` — нэвтрэх форм

## Шалгалтаар илэрсэн анхаарах зүйлс

1. Анхны архивт `app/dashboard/page.tsx` болон `app/dashboard/(overview)/page.tsx` **хоёулаа `/dashboard` URL** үүсгэх боломжтой байсан. Next.js-д route зөрчил үүсгэж болох тул хоёр дахь файлыг `page.example.tsx` гэж нэрлэн, жишээ кодыг нь хадгалсан. Үндсэн Dashboard `app/dashboard/page.tsx` хэвээр.
2. `isDemo()` нь `POSTGRES_URL` байхгүй үед жишээ өгөгдөл ашиглана. Ийм үед нэмэх/засах/устгах үйлдлүүд идэвхгүй байна.
3. `app/ui/invoices/status.tsx`-ийн одоогийн логик `paid`-аас бусад **бүх** утгыг `Төлөгдөөгүй` гэж харуулдаг. Өгөгдөл зөвхөн `paid`/`pending` байхаар хязгаарлагдсан үед тохирно.
4. Архивт зөвхөн `app` хавтас байна. `package.json`, `auth.ts`, `.env.local` болон бусад үндсэн төслийн файлууд байхгүй тул **бүтэн төслийг ажиллуулж/build хийж шалгаагүй**.
5. `actions.ts` дотор Zod-ийн `errorMap` ашигласан байна. Төслийн Zod хувилбараас шалтгаалж төрөл шалгалтын алдаа гарч болох тул өөрийн орчинд `npm run build` ажиллуулж шалгаарай.

## Буцааж хэрэглэх

ZIP доторх `app` хавтсыг төслийнхөө үндсэн `app` хавтастай нэгтгэхийн өмнө **хуучин хувилбараа нөөцлөөрэй**. Файлуудыг солихдоо VS Code дээр алдаа гарсан эсэхийг шалгана.
